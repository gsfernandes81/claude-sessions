## Agent messaging: a router heartbeat, and a peer-check that leaves nothing behind

- **The router writes a heartbeat**, `$HUB_QUEUE/.beat`, every minute: the time, how many
  containers answer, and how many messages wait. It is written only after the router has
  taken each of its locks, so a stuck router stops beating instead of reading healthy.
- **`peer-check` leaves nothing behind.** Through 0.18.0 each run left a dead session record,
  key and socket in the container's `~/.claude`, a cache directory per run, and a line in the
  registry's hook log. The checked claude now runs entirely in a scratch directory, is
  stopped by closing its input, and the directory goes after it.

For infra: pin this in place of 0.18.0. Point the router health check at `$HUB_QUEUE/.beat`
(`/home/dev/queue/.beat` in your compose), stale after about 3 minutes. Nothing else
changes from 0.18.0's list.

## The remote view, after a first day on the phone

Fixes and one feature, all in `claude-remote` and the relay's wire, from the owner's first use
of 0.11.0 on Termux (2026-11-01).

- **Claude's markdown is drawn as Claude Code draws it.** Headings lose their `#`s, `**`, `*`
  and `~~` become styles, and inline code and unlabelled code blocks are lavender. Lists use
  `-` bullets and number `1.`, `a.`, `i.` as they nest, and quotes are drawn behind `▎`.
  Tables are boxed (`┌─┬─┐`), with the header centred and the width shared out by Claude
  Code's rule. A table that won't fit is drawn as `Header: value` lines, as Claude Code does
  on a narrow terminal. Labelled code blocks are drawn plain, with no syntax highlighting.
- **Scrolling follows the finger.** A wheel report scrolls one line (Termux sends one for
  every line a finger travels; each used to scroll three). Scrolling back from a prompt drawn
  at the top of the screen now moves a line a step, where the first step used to jump a
  screen.
- **An answered question stays in the transcript**, drawn as Claude Code does:
  `● User answered Claude's questions:` then `⎿  · question → answer`. This works for
  questions answered live and for ones from before a resume.
- **The home says `⠋ connecting`** (mockup 10's frame) until the relay says hello, instead
  of "No claude session in this container".
- **`\` then Enter is a newline** in the prompt, as in Claude Code.

The wire: a question's `done` op gains `a`, its answers keyed by question text. An older
client ignores it. A newer client talking to an older relay gets no `a`, and draws the
question without its answer.

For infra: pin this release. Nothing else changes on the hub or in the containers. Each phone
or WSL machine needs the new static binary installed as `claude-remote`.

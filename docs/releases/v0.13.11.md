## Pastes stay minimised in the remote view's transcript

- **A prompt sent with a paste's stand-in is drawn in the transcript as it stood in the
  input box**, `[Pasted text #N +L lines]` and all, while it waits and once claude has it,
  as Claude Code's own transcript does. Claude still gets the paste whole. Only the view
  that sent it remembers the short form: another device, or the view restarted, draws the
  paste in full.

Nothing in the registry or the wire changes shape, and the hub and holder are unchanged. For
infra: pin this release as usual. The change is in the phone client (`claude-remote`), so
reinstall it there to see it.

## An answered question loses its `!` at once

- **Answering a question or permission prompt in the remote view clears the session's amber
  `!` straight away.** Claude fires no hook when a prompt is answered, so the `!` stood in
  the home tree until the turn ended, which in a long turn read as the question still asked.
  The holder sees every answer, and once the last prompt claude has open is answered (or
  claude withdraws it) it writes `PromptAnswered` to the slot's record, the event pi's
  `ui_prompt_end` already maps to, stamped at the answer, so a question asked later still
  shows. A terminal session is unchanged: its `!` clears when the turn ends.

Nothing in the registry or the wire changes shape. For infra: pin this release; the hub must
be rebuilt so the containers' volume carries it. A remote session already running keeps its
old holder until it is next opened or resumed. The phone client is unchanged and need not be
reinstalled.

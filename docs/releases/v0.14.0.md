## The remote view: background tasks, as Claude Code shows them

- **Background shells and monitors show on the mode line**, as Claude Code's pill does:
  `⏵⏵ auto mode on · 2 shells, 1 monitor`, and `/tasks to see subagents` while a background
  agent or workflow runs. A turn's end line says `· 1 shell still running` while they run.
- **`/tasks`, or Down on an empty prompt then Enter, opens the Background list**: running
  shells and monitors, local agents and workflows, by section when there is more than one
  kind, then the agents that finished under Completed. `x` stops the selected task.
- **Enter opens a task's details.** A shell or monitor shows its status, runtime, command
  and its latest output in a box, refreshed every two seconds while it is open. An agent
  shows its type, description, progress and the start of its prompt. With one task
  running, Down then Enter goes straight to it.

Not built yet: the agent strip under the footer, foregrounding an agent (`f`), and the
workflow's phases-and-agents browser.

The wire gains a `tasks` op and `tout`/`tstop` requests, which an older client or relay
ignores or refuses; the registry and the hub's home are unchanged. For infra: pin this
release as usual. Reinstall the phone client (`claude-remote`) to see it.

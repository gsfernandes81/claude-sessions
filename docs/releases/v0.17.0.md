## The remote view: agents' messages as Claude Code draws them, and no raw markup

- **A message from another agent** (a subagent's hand-back, another session's message, a
  teammate's) is no longer drawn as a prompt full of `<agent-message>` markup. Collapsed it
  is one grey line, `› Message from @general-purpose (ctrl+o to expand)`, as in Claude
  Code; Ctrl+O or `/expand` shows `› Message from general-purpose` with the report under
  it, its hand-back frame removed. A peer session's words go on the collapsed line where
  they fit. One that arrived mid-turn is drawn on a resume too.
- **Nothing of Claude Code's own wrapping is drawn as typed**: a replayed line opening with
  one of the tags Claude Code never shows as typed (`<system-reminder>`, `<tick>`,
  `<channel>`, …) is not a prompt, and `<local-command-stderr>` is a note.
- **Tool results as Claude Code shows them**: an error without `<tool_use_error>`, the
  model's reminders and `<sandbox_violations>` left out, and a `<persisted-output>`
  stand-in replaced by the shell's own output, or the preview claude kept.

The wire gains an item of kind `msg`, which an older client skips. The registry and the
holder are unchanged. For infra: pin this release as usual. Reinstall the phone client
(`claude-remote`) to see it.

## Messages within a container pass through the hub, with the sender's verified name

*Written after the release: none was at the tag.*

- **A message between two sessions of one container now arrives with the sender's listed
  name** (`claude-sessions/claude-2 tunnel cert renewal`), as one from another container
  does. Before, it carried what the sender's Claude Code called itself (`workspace-01`).
- **How.** The relay fronts each live local claude's inbox. It renames the claude's
  listening socket to `.real-<name>` beside it in `cc-socks`, which a listening Unix socket
  survives, and listens at the old path itself. The session's record, and its own idea of
  itself, still name that path, so it is not listed to itself; every other session reaching
  that path reaches the relay. The relay hands the message to the hub, the router routes it
  back into the same container, and the relay writes it into the moved socket with the
  sender's verified name. A reply comes back the same way.
- **A container's own offloaded sessions can be messaged**, and a message wakes one where
  there is room, as for another container's.
- **The sockets are put back** when the relay stops, loses its lock or switches itself off,
  so local sessions reach each other directly again. A relay killed outright cannot; the next
  agent puts them back as it starts.

For infra:

- **Local messaging now depends on the hub**, as messaging between containers already did.
  With the hub down the agents exit and put every socket back, so local sessions fall back to
  Claude Code's own direct delivery, with its names.
- **An agent killed outright** (SIGKILL, OOM) leaves its container's live sessions out of
  listings until the next agent starts, since Claude Code lists only a record whose socket
  answers.
- **A `claude` run outside a slot** can no longer message a slot's session in its own
  container. It has no address, so what it sends is dropped and logged, as it already was
  across containers.
- **The wire.** The router now routes within a container, and a roster carries `own`, the
  container's own slots, beside `you`. An agent from before 0.19.0 ignores both, and keeps
  Claude Code's own direct local delivery.
- **The phone client.** A 0.19.0 `claude-remote` works against a relay as old as 0.18.1. The
  wire is still version 1, and the relay's operations have not changed since 0.18.1. Against
  a hub and holders older than 0.18.3:
  - `/model` marks the resolved model rather than `Default (recommended)`;
  - `/effort` opens on its first stop rather than the session's own effort;
  - the bottom bar shows no effort.

  Against one older than 0.18.5, swap reads `?`.
- **No change to the drop-in, the volumes or the variables.** `hooks-config` is byte-identical
  to 0.18.5.

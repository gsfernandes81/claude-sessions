## The remote view: interrupting like the terminal, narration, step summaries, steady scrollback

- **Touch scrolling no longer jumps pages.** Scrolled back, older history loaded above the
  view was counted as lines arriving under it, so the view leapt back by the whole stretch
  (about five screens) each time, and a flick seemed to move many lines a step. The view now
  stays put while history loads above it.
- **No or Esc at a permission prompt stops the turn**, as Claude Code's No does, rather
  than letting Claude carry on. A No with words still tells Claude what to do instead.
- **A prompt sent while a shell command runs puts the command in the background** and the
  turn takes the prompt in at once (the owner's ask; the terminal would wait for it).
- **The narration Claude writes between tool calls is drawn**, as Claude Code draws it.
  Through 0.17.1 it was dropped with thinking, losing every line between steps.
- **A step's tool calls are said in Claude's own words** (`Listed root, read hostname`)
  rather than counted; Ctrl+O still expands them into the calls.

For infra: pin this release as usual. Both halves changed: the hub's relay and holder (the
holder now runs claude with `CLAUDE_CODE_EMIT_TOOL_USE_SUMMARIES=1`; the relay sends a new
`sum` op) and the phone client. Mixed versions work, an older client ignoring what it does
not know, but the new behaviour needs both. Reinstall `claude-remote` on the phone.

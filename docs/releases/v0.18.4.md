## The remote view: /mode, a mode line that stays, and Left twice to go home

- **`/mode` picks the permission mode from a list**: Manual, Accept edits, Plan and Auto,
  the session's own ticked and the cursor on it. `/mode plan` (or `manual`, `accept`,
  `auto`) sets one without the list. It replaces `/auto`, which cycled the mode.
- **The mode line stays through a turn**, as Claude Code 2.1.311's does, where
  `esc to interrupt` took its place: a mode changed mid-turn could not be seen, and was easy
  to step past. The default mode is drawn as Claude Code draws it, `⏸ manual mode on` in
  grey. Its hint is `(/mode to change)`.
- **Left twice on an empty prompt goes home**, the session left running, as Ctrl+\ and
  `/disconnect` do, after Claude Code's double Left to its agents view. The first says
  `Left again to disconnect`; the second must come within two seconds, with no other key
  between.
- **A command typed in full comes first in the suggestion list.** On a phone, claude's
  `auto-mode-setup` and `autocompact`, two lines each, filled the list and hid the view's
  own command.

For infra:

- **Nothing to change.** Only the phone client (`claude-remote`) changed: no change to the
  drop-in, the volumes, the variables, the registry, the wire or the hub. `hooks-config` is
  byte-identical to 0.18.3.

## The remote view in Claude Code's own colours

A colour fix in `claude-remote`. The owner said on 2026-11-01 that the remote view is not held
to a list of approved colours ("Termux is not so limited"), so it now uses Claude Code's
colours wherever Claude Code does. They are read from the dark theme in the `claude` 2.1.311
binary.

- **Each permission mode's line in its own colour**:
  - auto mode: yellow `ffc107`;
  - accept edits: purple `af87ff`;
  - plan mode: teal `48968c`;
  - bypass permissions: red `ff6b80`.

  Every mode used to be yellow.
- **Failures are red** (`ff6b80`, Claude Code's `error`):
  - a failed or stopped agent's or workflow's dot;
  - in the expanded view (Ctrl+O), a failed call's dot and its result;
  - a turn's error note, and "Interrupted".

  They used to be grey. A call or agent that worked gets a green dot, as before.

Nothing changes on the wire, the hub or the containers. For infra: pin this release. Each phone
or WSL machine needs the new static binary installed as `claude-remote`.

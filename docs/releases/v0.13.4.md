## The remote view: reading back holds still, and words at a time

Two changes to `claude-remote`, asked for by the owner on 2026-11-02.

- **Scrolled back, the view holds still.** New output arriving below no longer moves what you
  are reading. Scrolled back to the bottom, it follows the output again.
- **Ctrl or Alt with Left or Right goes a word at a time** in the prompt: back to the start of
  a word, on to the end of one. This matches Claude Code 2.1.311's prompt, read off its screen.
  Shift with an arrow is still that arrow.

Nothing changes on the wire, the hub or the containers. The relay is as in 0.13.3. For infra:
pin this release. Each phone or WSL machine needs the new static binary installed as
`claude-remote`.
